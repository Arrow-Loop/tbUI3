Development prerelease of tbUI3IDE 0.4.0.8 for twinBASIC BETA 1043 through 1045. Includes Updater 0.2.0.4 and both Win32 and Win64 add-in DLLs.

## What's changed

- Optimized Welcome Wizard initialization to eliminate costly character-by-character processing of large interface resources.
- Centered the Welcome Wizard within the IDE application area.
- Added theme-aware WinUI 3-style modal shadows.
- Expanded startup diagnostics to identify individual initialization delays.

## Known issues and testing status

- First-run startup timing, modal positioning and appearance still require native acceptance.
- Four previously identified BETA 1045 Ribbon fixture failures remain unresolved (File/Save, native menu capture, compact alignment and sizing, and asynchronous Insert Add).
- Development testing is prioritized on BETA 1043 and 1044. This is not a stable or team-deployment release.

Both compiled DLLs and the embedded updater and themes passed release-package verification.
